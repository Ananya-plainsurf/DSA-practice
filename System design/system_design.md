# 🚀 System Design Roadmap (Frontend / Fullstack Interview Focus)

---

# 🟢 Phase 1 — Foundations

## Goal

Understand how web applications work end-to-end.

### Topics

1. Client-Server Architecture
2. DNS
3. HTTP / HTTPS
4. APIs (REST + GraphQL)
5. SQL vs NoSQL
6. Database Basics
   - tables
   - joins
   - normalization

✅ Outcome:

```txt id="b7g2wc"
Understand request flow from browser → server → database
```

---

# 🟡 Phase 2 — Core Scaling Concepts ⭐

## Goal

Understand why systems become slow and how they scale.

### Topics

1. Vertical Scaling
2. Horizontal Scaling
3. Load Balancers
4. Caching
   - Redis
   - cache invalidation

5. Replication
6. Database Indexing ⭐
7. CDN

✅ Outcome:

```txt id="k1kzj4"
Understand performance bottlenecks and scaling basics
```

---

# 🟠 Phase 3 — Distributed Systems

## Goal

Understand how large distributed systems work.

### Topics

1. Sharding
2. Partitioning vs Sharding
3. CAP Theorem
4. Message Queues
5. Reverse Proxy
6. Rate Limiting
7. WebSockets
8. API Gateway
9. Authentication & Authorization

✅ Outcome:

```txt id="d7c5f2"
Understand distributed system tradeoffs and traffic handling
```

---

# 🔴 Phase 4 — Architecture Practice ⭐⭐⭐

# MOST IMPORTANT PHASE

## Goal

Combine concepts into real systems.

### Design Problems

1. URL Shortener
2. Rate Limiter
3. Chat / WhatsApp
4. Notification Service
5. Twitter / Instagram Feed
6. YouTube / Netflix

---

## Practice Method

```txt id="r7gh1s"
Design yourself first
→ identify bottlenecks
→ compare with reference
→ refine
```

Ask:

- Why cache?
- Why shard?
- Why MQ?
- What fails first?
- What are tradeoffs?

✅ Outcome:

```txt id="z9v6ka"
Real system design thinking
```
